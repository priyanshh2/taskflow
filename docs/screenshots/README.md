# TaskFlow Screenshots Guide & Checklist

This folder is designated for application screenshots referenced in [`USER_MANUAL.md`](../USER_MANUAL.md).

## Screenshot Checklist

When capturing screenshots of the live application at **[https://taskflow-b51e6.web.app](https://taskflow-b51e6.web.app)**, save each image into this directory using the exact filenames listed below:

| File Name | Target Screen & State | Relevant Section in User Manual |
| :--- | :--- | :--- |
| `01-landing-login-page.png` | Initial landing screen showing TaskFlow header, logo, and "Continue with Google" sign-in card. | Section 3: Accessing the Application |
| `02-google-sign-in-popup.png` | Google OAuth popup dialog showing Google account chooser. | Section 4: Signing In with Google |
| `03-dashboard-overview.png` | Full dashboard view showing user avatar, name, email, "Create New Task" form, and task list area. | Section 5: Understanding the Dashboard |
| `04-task-creation-form.png` | "Create New Task" form filled out with a sample Title (e.g., "Prepare weekly project status update") and Description. | Section 6: Creating a New Task |
| `05-task-created-success.png` | Dashboard with green success alert banner: *"Task successfully created and saved to Cloud Firestore."* | Section 6: Creating a New Task |
| `06-task-list-and-filters.png` | Task list section showing multiple tasks with active filter tabs (`All`, `Planned`, `In Progress`, `Complete`) and counts. | Section 7: Viewing & Filtering Tasks |
| `07-status-change-dropdown.png` | Close-up of a task card showing the status dropdown menu open, demonstrating status change to *"In Progress"*. | Section 8: Updating Task Status |
| `08-sign-out.png` | Top header highlighting the "Sign out" button and user profile bar. | Section 9: Signing Out |

## Recommended Screenshot Specifications
- **Format:** PNG (`.png`)
- **Recommended Resolution:** 1920x1080 (Desktop view) or high-DPI browser capture.
- **Tools:** Windows Snipping Tool (`Win + Shift + S`), browser screenshot tool (`Ctrl + Shift + I` &rarr; Run command &rarr; "Capture full size screenshot"), or macOS `Cmd + Shift + 4`.
